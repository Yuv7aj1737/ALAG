## 🚀 Inicio Rápido

```bash
# 1. Navega a la carpeta
cd temprolbot

# 2. Instala dependencias
npm install

# 3. Configura el token en .env
# (Edita .env y reemplaza 'tu_token_aqui' con tu token de bot)

# 4. Inicia el bot
npm start
```

